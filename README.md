# 🎀 Kelmans Tanks vs Zombies 🎀

A vibrant, action-packed web-based tank shooter game where you defend against endless waves of zombies! Built with pure HTML5 Canvas and JavaScript - no external dependencies.

![Game Screenshot](screenshot.png)

## 🎮 Play Now

Simply open `index.html` in any modern web browser, or deploy to GitHub Pages for instant online play!

## ✨ Features

### Cross-Platform Gameplay
- **PC**: Mouse aiming + shooting, WASD/Arrow keys for movement
- **Mobile & iPad**: Dual thumbstick controls with on-screen weapon buttons
- Responsive design adapts to any screen size

### Weapons System
| Weapon | Controls | Description |
|--------|----------|-------------|
| 🔫 Bullets | Mouse click / Right thumbstick | Rapid fire, upgradable damage & speed |
| 💣 Bombs | B key / Bomb button | 3 per wave, massive area damage |
| ⚡ Laser | L key / Laser button | 2 per wave, 1-second beam, 15s recharge |

### Progression
- **Endless Waves**: Survive as long as possible against escalating difficulty
- **Boss Battles**: Defeat a massive boss at the end of each wave
- **Upgrade System**: Between waves, upgrade:
  - Bullet damage, speed, and fire rate
  - Bomb capacity
  - Laser duration and recharge speed
  - Max health and shield capacity
  - Tank movement speed

### Zombie Types
- **Normal** (Purple): Standard speed and health
- **Fast** (Pink): Quick but fragile
- **Tank** (Dark Purple): Slow but heavily armored
- **Boss** (Red/Orange): Massive health, multiple phases

### Visual Style
- Barbie-inspired bright pink and purple color palette
- Glowing neon effects
- Particle explosions and screen shake
- Animated boss with rotating spikes

## 🚀 How to Run

### Local Play
1. Download or clone this repository
2. Open `index.html` in your browser
3. Start playing!

### GitHub Pages Deployment
1. Fork or upload this repository to GitHub
2. Go to **Settings** → **Pages**
3. Select source: **Deploy from a branch** → **main** → **/(root)**
4. Your game will be live at `https://yourusername.github.io/repository-name/`

